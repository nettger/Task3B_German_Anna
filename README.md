## Запуск

1. Распакуйте архив в отдельную папку.
2. Откройте `index.html`.
3. Нажмите «Загрузить пользователей». Для работы приложения требуется интернет.

## Структура

- `index.html` — интерфейс приложения.
- `style.css` — оформление и адаптивная сетка карточек.
- `app.js` — запросы к REST API, обработчики событий, фильтрация и обновление DOM.

## Результаты проверок

Синтаксис JavaScript проверен. Логика протестирована автоматически с данными JSONPlaceholder, моделью DOM и имитацией ошибок HTTP и сети:

| Проверка | Результат |
| --- | --- |
| Загрузка пользователей | 10 карточек с именем, email и городом |
| Поиск `lEaNNe` | Найдена Leanne Graham, новый запрос не отправлен |
| Поиск неизвестного имени | Сообщение «Пользователи не найдены» |
| Просмотр публикаций Leanne | GET-запрос с `userId=1`, показаны первые 3 публикации |
| Ожидание ответа | Отображается «Загрузка...», кнопка загрузки отключена |
| Ошибка HTTP 404 | Сообщение об ошибке, кнопка снова доступна |
| Сетевой сбой | Сообщение об ошибке, возможна повторная попытка |
| Повторная загрузка | Список успешно обновляется |

Для ручной проверки откройте страницу в браузере и повторите перечисленные действия. Чтобы проверить реальную ошибку 404, временно замените `/users` на `/userz` в функции `loadUsers` файла `app.js`, нажмите кнопку загрузки. Затем верните `/users`, сохраните файл, обновите страницу и убедитесь, что пользователи снова загружаются.
